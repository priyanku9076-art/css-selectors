CSS Selectors Task

A basic web development project demonstrating the use of fundamental CSS selectors to style HTML elements.

📌 Features & Concepts used

Linking an external CSS stylesheet (style.css) to an HTML file.

Styling elements using Element/Tag selectors (p, body).

Styling elements using Class selectors (.head).

Styling elements using ID selectors (#bglime, #para).

Targeting specific inline elements using Descendant selectors (#bglime span, ul li span).

🛠️ Built With

HTML

CSS

🚀 How to Run 

Clone or download this repository to your local machine.

Open index.html directly in any web browser.
